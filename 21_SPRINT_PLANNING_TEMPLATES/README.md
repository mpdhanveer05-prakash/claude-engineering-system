# 21_SPRINT_PLANNING_TEMPLATES

| File | When |
|------|------|
| `SPRINT_PLAN.md` | Day 1 of sprint |
| `STANDUP.md` | Daily |
| `DEMO_NOTES.md` | Last day of sprint |
| `RETRO.md` | Last day of sprint, after demo |
| `BACKLOG_GROOMING.md` | Mid-sprint, async or sync |

Default cadence: 1-week sprints for small teams, 2-week for >5 engineers.

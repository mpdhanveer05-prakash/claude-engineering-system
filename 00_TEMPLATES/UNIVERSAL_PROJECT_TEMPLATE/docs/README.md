# docs/

> All human + AI documentation. Each subfolder owns one slice.

| Folder | Owns |
|--------|------|
| `architecture/` | System design, ADRs, diagrams, dependency maps |
| `api/` | API reference + OpenAPI/GraphQL specs |
| `database/` | Schema, migration policy, backup policy, ERDs |
| `product/` | PRDs, BRDs, market notes |
| `business/` | Pricing, contracts, business rules |
| `design/` | Design system, tokens, brand |
| `security/` | Threat model, security guide, compliance |
| `deployment/` | Deployment guide, environment matrix |
| `runbooks/` | Operational runbooks (incident response, rollback, etc.) |
| `observability/` | SLOs, dashboards, alerts |
| `performance/` | Budgets, benchmarks, optimization notes |
| `releases/` | Per-release notes |
| `onboarding/` | How a new dev / Claude gets productive |
| `standards/` | Project-specific overrides of workspace standards |

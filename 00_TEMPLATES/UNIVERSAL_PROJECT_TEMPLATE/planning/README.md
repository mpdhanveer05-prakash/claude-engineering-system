# planning/

> Work-in-progress artifacts. Distinct from `docs/` which is reference.

```
planning/
├── features/   # one .md per feature, named <slug>.md
├── sprints/    # one folder per sprint: sprint-NN/
├── roadmap/    # ROADMAP.md, OKRs, themes
└── bugs/       # one .md per bug, named BUG-NNN-<slug>.md
```

| File | Template |
|------|----------|
| Feature one-pager | `_TEMPLATE-feature.md` |
| Sprint plan | `sprints/_TEMPLATE-sprint.md` |
| Bug report | `bugs/_TEMPLATE-bug.md` |
| Roadmap | `roadmap/ROADMAP.md` |

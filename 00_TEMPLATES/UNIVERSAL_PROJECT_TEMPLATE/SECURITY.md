# Security Policy

## Supported versions
Latest minor on the current major receives security fixes.

## Reporting a vulnerability
Email **security@{DOMAIN}** with:
- Vulnerability description and impact
- Reproduction steps or PoC
- Affected versions
- Your contact info (optional)

We acknowledge within **48 hours** and aim to resolve within **90 days** under coordinated disclosure.

## Out of scope
- Self-XSS that requires the victim to paste attacker-supplied code into devtools
- Issues only exploitable with physical access
- Volumetric DoS

## Hall of fame
We credit reporters in release notes (with permission).

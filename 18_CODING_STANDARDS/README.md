| `TYPESCRIPT.md` | TS strict mode, idioms |
| `PYTHON.md` | Python 3.12+ idioms, mypy strict |
| `GO.md` | Go conventions |
| `RUST.md` | Rust conventions |
| `SQL.md` | SQL style |
| `REACT.md` | React component patterns |
| `TESTING.md` | Test pyramid + conventions |
| `COMMENTS.md` | When (and when not) to comment |
